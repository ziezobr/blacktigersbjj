# Black Tigers BJJ

Site: https://ziezobr.github.io/blacktigersbjj/

Static HTML, CSS and JavaScript. Authentication, data and private media use Supabase. Only the publishable key belongs in this repository.

Deploy with GitHub Pages from main / (root). The /blacktigersbjj base is required for navigation, assets, locale routes and authentication redirects.

The original source is maintained in the BJJ workspace; export using scripts/export-github-pages.mjs.
